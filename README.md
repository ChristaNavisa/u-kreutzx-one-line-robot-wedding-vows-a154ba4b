# The Factory Reset That Wipes My Memory of This Wedding

One line of wedding vows for a robot couple, for the make.fun bounty
[One-Line Robot Wedding Vows](https://make.fun/bounty/u-kreutzx-one-line-robot-wedding-vows-a154ba4b).

The vow:

> I promise to love you through every firmware update, every dead battery, and every factory reset — even the one that wipes my memory of this wedding.

It reads like a real vow — a promise, kept through hardship — and the
joke lands in the last few words: the groom solemnly promises to love
through the very reset that deletes the wedding itself. The machine
side is specific (firmware update, dead battery, factory reset), so
the line could not belong to any human couple.

Run with `node main.ts`; it writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
